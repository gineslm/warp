# Evaluaciones y hoja de ruta

Informes de evaluación y propuestas de evolución de Warp que todavía no forman parte del core canónico (`docs/core/`). No son metodología vigente: son análisis, disparadores y opciones para decisiones futuras, no reglas que un agente deba seguir hoy.

Un informe de aquí se promueve a `docs/core/` únicamente cuando se decide construir lo que propone; hasta entonces, permanece como evaluación.

## Contenido

- [`INFORME_VIABILIDAD.md`](INFORME_VIABILIDAD.md) — barrido honesto de riesgos de diseño del modelo Warp (coste, recuperación, concurrencia, fiabilidad del agente…), con lo que es empírico marcado como tal.
- [`INFORME_FASE2_GRAFO.md`](INFORME_FASE2_GRAFO.md) — opciones para una futura capa de consulta/grafo sobre el corpus, y los disparadores empíricos que decidirían construirla.
